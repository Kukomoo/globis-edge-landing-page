What is Globis Edge?

Globis Edge turns IDs, notes, and spoken testimony into structured intake records directly on a Raspberry Pi 5, so teams can keep working when cloud access is unreliable.

📥 Capture messy inputs Audio, OCR, handwritten notes, and typed caseworker context.
🧭 Structure the case Turns fragmented information into reviewable intake records.
🛡️ Keep humans in control Flags conflicts and blocks sensitive fields before final review.

1,500+ Word Technical Writeup

Complete Kaggle submission covering problem, architecture, five hero capabilities, challenges, and responsible AI implementation

What's Inside:
  • The Problem: Caseworkers at Adré, Chad process 40+ intakes daily with fragmented data, no conflict detection
  • Architecture: Tiered Gemma 4 inference (Scout 2B + Analyst 4B), multimodal intake, cross-modal conflict resolution
  • Five Hero Capabilities: Tiered inference routing, multimodal ingestion, conflict detection, constitutional auditing, dignity loop
  • Edge Reality: Runs on Pi 5 (8GB RAM), ~11-12s end-to-end latency, zero cloud dependency
  • Challenges & Solutions: SQLite vulnerability mitigation, race condition handling, quarantine signaling, protected field logging
  • Why Gemma 4: Multimodal, native function calling, scale-invariant instruction-following, fits 8GB hardware
  • Safety Guarantees: Rule-first auditing, fail-closed design, synthetic data only, value-masked logging
