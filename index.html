What is Globis Edge?

Globis Edge is an offline, on-device caseworker companion for refugee reception centres operating in low-connectivity environments. It turns fragmented identity documents, multilingual testimony, and handwritten notes into structured, audit-safe intake records.

Built for:

  • Caseworkers processing diverse identity documents
  • Interpreters translating oral testimony
  • Protection staff ensuring ethical data handling
  • Field settings with no reliable internet

Core Capabilities

🎯

Tiered Inference

Fast 2B Scout model for translation & light checks. Powerful 4B Analyst for multimodal synthesis.

🎤

Multimodal Intake

Transcribe audio, extract text from documents via OCR, process typed notes—all in one unified pipeline.

⚠️

Conflict Resolution

Detect mismatches across modalities. Never auto-resolve—always human-in-the-loop review.

🛡️

Constitutional Audit

Dual-pass (rule + reasoning) verification. No political affiliation, no ethnic classification, fail-closed design.

🔒

Encrypted Persistence

SQLCipher with value-masked logging. No sensitive data in plain text. Append-only quarantine for audit trail.

📱

Edge Deployment

Runs offline on Raspberry Pi 5 with 8GB RAM and 500GB SD card. True offline-first. No cloud dependency.

⚡

Powered by Gemma 4

Google's multimodal AI model enabling advanced inference on edge devices with native function calling and tool use.

1,500+ Word Technical Writeup

Complete Kaggle submission covering problem, architecture, five hero capabilities, challenges, and responsible AI implementation

What's Inside:
  • The Problem: Caseworkers at Adré, Chad process 40+ intakes daily with fragmented data, no conflict detection
  • Architecture: Tiered Gemma 4 inference (Scout 2B + Analyst 4B), multimodal intake, cross-modal conflict resolution
  • Five Hero Capabilities: Tiered inference routing, multimodal ingestion, conflict detection, constitutional auditing, dignity loop
  • Edge Reality: Runs on Pi 5 (8GB RAM), ~11-12s end-to-end latency, zero cloud dependency
  • Challenges & Solutions: SQLite vulnerability mitigation, race condition handling, quarantine signaling, protected field logging
  • Why Gemma 4: Multimodal, native function calling, scale-invariant instruction-following, fits 8GB hardware
  • Safety Guarantees: Rule-first auditing, fail-closed design, synthetic data only, value-masked logging
